# どうぶつクイズ

子ども向けの動物クイズWebアプリです。動物の名前を見て、2つの写真から正しいほうを選びます。

🔗 https://shirotan0708.github.io/animal-quiz-game/ (GitHub Pages有効化後にアクセス可能)

## あそびかた

1. 「スタート！」を押す
2. あそびたいジャンルを選ぶ(すべて / ほ乳類 / 鳥 / 魚・海の生き物 / は虫類 / 両生類 / 虫)
3. 表示された動物名に合う写真を2択から選ぶ
4. 全問終わるとスコアと★評価が表示される

出題はカテゴリ内でランダムに選ばれ、間違いの選択肢もできるだけ同じなかま(哺乳類なら哺乳類など)から出るため、似た動物を見分ける力が身につきます。1回のプレイは最大15問(カテゴリの動物数が少ない場合はその数まで)。

## 特徴

- 動物の写真はWikipedia(ja)から実写真を自動取得。取得できない場合は絵文字にフォールバックするため、オフラインでも遊べる
- 動物データは約90種類、6カテゴリ(哺乳類・鳥類・魚/海の生き物・は虫類・両生類・昆虫)
- 外部ライブラリなし、`index.html` 単体で完結

## 使い方(ローカル)

`index.html` をブラウザで開くだけで動作します。ビルドや依存関係のインストールは不要です。
